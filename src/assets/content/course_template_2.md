# Writing a chapter

This is template content. A chapter is a plain markdown file — the same format as any article on the site. There is nothing course-specific inside the file itself; the manifest is what turns it into a chapter.

## Headings drive the table of contents

Every second-level heading becomes an entry in the table of contents shown alongside the chapter. Use them to break the chapter into scannable sections. A chapter with only one section shows no table of contents, so aim for a few.

## Keep sections short

Write the way the rest of the site does: lead with the situation, then the point. A reader who understands the problem will draw the conclusion themselves.

This paragraph is filler so the section has enough body to render like a real one. Swap it for your own writing.

## Images are optional

An image placed before the first heading becomes the lead image at the top of the page. Leave it out and the chapter opens straight into the text. Either works.

## The reader never has to hunt for the next step

When this file is listed in a course manifest, the foot of the page gains previous and next links and a way back to the hub. You do not add those — they appear because the manifest knows the order.
